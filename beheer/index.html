KAIJUCLUB / BEHEERTOEGANG

Jouw garage.
Jouw controle.

Verbind één keer je beheertoegang. Daarna voeg je hier foto’s en wageninformatie toe, met een direct voorbeeld van je site.

Een fine-grained sleutel (github_pat_) of klassieke sleutel (ghp_) werkt. Je GitHub-account moet schrijfrechten hebben op Kaijuclub_kc.
Dit wachtwoord beveiligt de opgeslagen sleutel op dit toestel.

Open beheer in een apart tabblad ↗
Eerste keer verbinden?

Je hebt een beheersleutel van jullie GitHub-account nodig. Die geeft dit beheerscherm toestemming om de wagenfiches en foto’s in jullie website op te slaan.

  1. Open Beheersleutel aanmaken en log in bij GitHub.
  2. Kies Resource owner: alldaydigital. Kies daarna bij Repository access → Only select repositories alleen Kaijuclub_kc.
  3. Geef bij Repository permissions → Contents de toegang Read and write. Metadata wordt automatisch toegevoegd.
  4. Klik Generate token en plak de sleutel uitsluitend in het veld hierboven.
  5. Vink Onthoud deze verbinding aan en kies een eigen wachtwoord van minimaal 12 tekens om later op dit toestel met dat wachtwoord in te loggen.
Beheersleutel aanmaken ↗

Kun je alldaydigital niet kiezen, bijvoorbeeld als externe bijdrager? Gebruik een klassieke beheersleutel ↗ met alleen public_repo. Een klassieke sleutel kan meerdere openbare repositories van je account bereiken; een fine-grained sleutel beperkt de toegang tot de gekozen repository.

Jullie website-repository is openbaar. Concepten staan niet op de website, maar opgeslagen foto’s en gegevens zijn via GitHub zichtbaar.
